Install Space City
your way

Use it instantly in the browser, pin it as a web app, or run the standalone desktop build. Houston is live today. LA, New York, Austin, San Antonio, Boston, and more unlock in the same app as they ship. Builds update often via continuous integration.

Recommended

Web app install

Add Houston Traffic Simulator to your home screen or desktop from Chrome, Edge, or Safari. Same live sim, app like window.

  • One click install when the browser offers it
  • Works on Windows, macOS, ChromeOS, Android
  • Always opens the latest hosted build
Or open in browser

If the install button stays quiet, open the sim in Chrome/Edge → menu → Install app / Cast, save, and share.

Desktop

Windows standalone

Portable style package for Windows 10/11. Unzip and run. Ideal for demos, classrooms, and kiosks.

  • x64 build · no store account required
  • Includes launcher + local static host notes
  • Optional API keys via .env.local
Download for Windows Desktop setup guide

Package ships as a zip with a README. Replace the placeholder zip after you run npm run package:win.

macOS / Linux

Run from source

Best path on Mac and Linux today: clone, install, and launch the Vite app, or build a static folder for any local server.

  • npm install && npm run dev
  • npm run build → serve dist/
  • See developer docs for Electron packaging
