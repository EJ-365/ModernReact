I built Houston Traffic Simulator as a living postcard of Space City, and as the first city in a growing atlas. Los Angeles, New York, Austin, San Antonio, Boston, and more metros are on the way, each with its own freeways and sky.

Why this exists

Houston isn’t a postcard grid. It’s spaghetti freeways, sudden storms, and a sky that never sleeps. I wanted a simulator that feels like here, not a generic city skin.

Every district label, flood corridor, and runway rabbit is a small thank you to the metro that raised the idea, and a template for the cities that follow.

What I care about

  • Live data when it makes the city truer
  • Honest modeling when APIs can’t reach
  • UI that stays cute without getting in the way
  • A multi city platform that still feels local

City roadmap

Live: Houston. Coming soon: Los Angeles, New York, Austin, San Antonio, Boston, plus more (DFW, Chicago, Miami, Seattle, and others) as the platform grows.

Same craft for every metro: live weather, traffic context, airports, landmarks, and hazard overlays tuned to that place, not a copy paste skyline.

Updated often · continuous integration

New features and fixes ship on a continuous cadence. Every push and pull request runs GitHub Actions CI: install, page checks, and a full production build, so the site and simulator stay release ready.

Web app users get updates on refresh; desktop packages rebuild from CI artifacts. The same pipeline will carry future cities.
