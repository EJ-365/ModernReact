Ship it

Desktop packaging

Two paths: a portable Windows zip for demos, or an Electron shell for a true standalone .exe.

Quick Windows zip (included script)

npm run build
npm run package:win

Writes downloads/HoustonTrafficSimulator-Setup-win-x64.zip containing the static dist/ build plus a README launcher guide. Host that zip at the Download page URL.

What’s in the zip

  • Production static site (index.html, app.html, assets)
  • README-DESKTOP.txt — how to open locally
  • Note: live API proxies need a tiny local server (npx serve won’t proxy keys; use npm run preview or Electron)

Electron (optional)

npm install --save-dev electron electron-builder
# add main process that loads http://localhost:5176/app.html in dev
# or loads file:// dist/app.html / custom static server in prod
npm run dist:win   # after you wire electron-builder

For classroom kiosks, prefer Electron + a local proxy so TranStar/airplanes.live keep working offline-from-browser but online-to-APIs.

Web install (no download)

Most users should use Install web app — zero packaging, always current.
