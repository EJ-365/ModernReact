# Developer documentation

HTML docs live in this folder and are part of the Vite multi-page app.

| File | Topic |
|------|--------|
| `index.html` | Docs home / project map |
| `getting-started.html` | Install & run |
| `architecture.html` | Runtime, proxies, hazards, PWA |
| `api-keys.html` | Environment secrets |
| `desktop.html` | Windows zip & Electron notes |
| `ci.html` | Continuous integration & update cadence |
| `contributing.html` | Contribution guidelines |
| `PROGRESS.md` | Build progress log (v10.8 → v10.16.4) |

With `npm run dev`, open **http://localhost:5176/docs/**.
