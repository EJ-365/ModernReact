Configuration

API keys

Paid APIs are hard-disabled. The sim runs on free / open public feeds only. Do not add commercial keys.

Do not set (billing risk)

  • FLIGHTAWARE_API_KEY — AeroAPI (paid). Proxies return 503.
  • TOMTOM_API_KEY — Traffic API (paid). Proxies return 503.

On Netlify: delete both env vars if they still exist, then redeploy after the free-feeds release is pushed.

Free stack (no billing)

  • Open-Meteo — weather
  • NWS / NHC / SPC — alerts & storm outlooks
  • Houston TranStar — public RSS traffic (Houston)
  • OpenSky / airplanes.live / adsb.lol / adsbdb / hexdb — aircraft
  • Nominatim / OSM — geocoding / map data (fair-use)

Environment file

# .env.local — leave paid keys commented out
# FLIGHTAWARE_API_KEY=
# TOMTOM_API_KEY=
# Optional TranStar agency JSON (not a commercial billable key):
# TRANSTAR_SPEED_URL=
# TRANSTAR_INCIDENT_URL=
# TRANSTAR_CLOSURE_URL=

Security

Never put secrets in client code or a VITE_ variable. Google Fonts / “open in Maps” links are free website loads, not billed developer APIs.
