Configuration

API keys

Most of the sim runs without secrets. Keys unlock richer live boards and flow.

Environment file

# .env.local (never commit)
FLIGHTAWARE_API_KEY=
TOMTOM_API_KEY=
# Optional TranStar authenticated JSON endpoints:
# TRANSTAR_SPEED_URL=
# TRANSTAR_INCIDENT_URL=
# TRANSTAR_CLOSURE_URL=

What needs a key?

  • Open-Meteo weather — no key
  • TranStar public RSS — no key
  • ADS-B / OpenSky — no key (rate limits apply)
  • FlightAware AeroAPI — airport boards + route enrichment
  • TomTom Traffic — optional flow / incident fill-in

Security

Vite injects keys only in server middleware. Do not prefix traffic secrets with VITE_ or they will leak into the client bundle.
