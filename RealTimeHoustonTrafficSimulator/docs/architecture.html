Internals

Architecture

Two surfaces share one Vite app: a marketing shell and a Three.js simulator driven by metro-specific runtime packs.

Surfaces

  • Marketing — index.html, about.html, download.html, docs/* styled by public/site/.
  • Simulator — app.html and src/app-main.js (scene graph, vehicles, weather, hazards, flights, airport boards, and city-pack UI).

Runtime loop (simulator)

frame(now)
  ├─ time / weather blend (Open-Meteo)
  ├─ trafficTick → congestion colors
  ├─ moveVehicles + signals / floods / hazards
  ├─ flights + crowds + hotspot rings
  └─ render Three.js scene

Live data path

Browser calls same-origin /api/*. Vite middleware and Netlify/Vercel functions proxy public feeds: TranStar, Google News RSS, airplanes.live, Open-Meteo, NWS, and other free ADS-B providers. Paid APIs are disabled and no secrets ship to the client bundle.

Roads and city packs

Each city pack supplies researched roads, districts, airports, weather filters, and route metadata. Houston boots a quality-checked OSM freeway/ramp set; the app rejects individual geometries with high reversal or duplicate-point rates before road meshes are built. Arterials and local streets stream through the OSM LOD layer.

Flight and news data

Live ADS-B aircraft are normalized into flight cards and airport arrivals/departures reconstructed from confirmed or inferred active routes. Tracking links open globe.airplanes.live. Local-news cards request a metro-specific Google News RSS feed via /api/news; the UI degrades to an offline notice if the free upstream feed is unavailable.

Hazard system

window.HAZARD toggles educational overlays. Flood mode paints FLOOD_CERTAIN footprints + bayou ribbons. Nuclear mode scales rings from NUK_YIELDS (1 kt → 1 Mt).

PWA

manifest.webmanifest + sw.js cache the marketing shell and app.html for installable / offline-tolerant launches. API routes are never cached.

CI

GitHub Actions (.github/workflows/ci.yml) builds on every push/PR. See CI & updates. The project is updated often; green CI is the gate for shipping.

Coordinate system

World units anchored at Downtown Houston (29.7604, -95.3698) with UNITS_PER_MILE = 210. geoToWorld / worldToGeo convert landmarks and live aircraft.
