Contributing

Created by Ejay Gabriel. Improvements that make Houston feel truer are always welcome. The project updates often — CI must stay green.

Guidelines

  • Keep marketing pages flexible and mobile-friendly.
  • Prefer small, focused changes in app.html — bump the #vtag / console build string when behavior changes.
  • Never commit .env.local or API keys.
  • Hazard overlays must stay clearly labeled as simulations.
  • Match the existing visual language (teal / sun / coral on deep navy) — avoid generic purple-AI defaults.
  • Run npm run ci (or rely on GitHub Actions) before merging — build must pass.

CI checklist

  • PRs trigger .github/workflows/ci.yml
  • Required pages and PWA assets must exist
  • npm run build must succeed
  • See CI & updates for the full pipeline

Suggested contribution areas

  • More accurate road / bayou geometry
  • Additional suburb fun facts
  • Performance passes on instancing
  • Electron packaging polish
  • Accessibility on the marketing site
  • Multi-city modules (LA, NYC, Austin, …)
