Setup

Getting started

Run the marketing site and the 3D simulator locally in a few minutes.

Requirements

  • Node.js 20+ (18+ may work)
  • npm 9+
  • Modern browser (Chrome / Edge recommended for PWA install)

Install & run

cd RealTimeHoustonTrafficSimulator
npm install
npm run dev

Open http://localhost:5176/ for the marketing site, or http://localhost:5176/app.html for the simulator.

Live feeds (free only)

Copy .env.example → .env.local if you need optional TranStar agency URLs. Do not set TomTom key — it is hard-disabled to prevent billing.

cp .env.example .env.local
# leave TOMTOM_API_KEY commented out

Production build

npm run build
npm run preview

Static assets land in dist/. Deploy to Netlify or Vercel to enable the included same-origin proxies for free local news and public flight feeds; API routes are never cached.

Web app install

With the site served over HTTPS (or localhost), Chrome/Edge will fire beforeinstallprompt. Use Download → Install web app, or the browser’s Install menu.
